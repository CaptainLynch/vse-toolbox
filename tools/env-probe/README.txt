VSE Toolbox 环境采集（只读，约 1 分钟，不需要管理员，不需要 Python）
=====================================================================

1. 把整个压缩包解压到桌面（右键 → 全部解压缩）。
2. 如果平时有在用 VSE Toolbox，先把它打开（这样能多采集一些使用统计）。
3. 关掉所有 Excel 窗口（脚本会在后台短暂打开一次 Excel，测试自动化能不能用）。
4. 双击 RUN-ME.cmd。
   - 如果出现蓝色的"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。
   - 黑色窗口里会一行行显示进度，最后出现"完成"，并自动打开桌面上的结果。
5. 桌面会多出一个 VSE-env-日期-时间.zip。先双击打开里面的 summary.txt 看一遍，
   确认没有你不想发出去的内容。
6. 打开 questionnaire.txt 填写问卷并保存。
7. 把 VSE-env-xxxx.zip 和 questionnaire.txt 一起发回来。

这个脚本不会采集：密码、Cookie、登录令牌、凭据库、数据库文件、报表/日志的正文内容。
用户名和电脑名会被替换成 <user>、<pc>。
它会做三个无害的小测试，测完立即删除：在你的用户目录建一个临时文件夹，
在注册表 HKCU 下建一个临时项，复制系统自带的 whoami.exe 到临时文件夹运行一次。
不想做这些测试的话：在本文件夹空白处按住 Shift 右键 → "在此处打开 PowerShell 窗口"，
输入  .\RUN-ME.cmd -NoWriteTest  回车。

如果 RUN-ME.cmd 一闪而过或报错：截图发回来，然后只填问卷的 E 部分即可。
请不要为了运行它去改公司电脑的安全设置。
