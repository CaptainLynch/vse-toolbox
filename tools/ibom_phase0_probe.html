iBOM 取证工具

阶段 0A 只读取证：一次运行导出 DMM 列表、样本明细、审批流和报表原件。只调用查询与导出接口，不发起审批、不保存、不删除。

方式一：书签（推荐）

  1. 按 Ctrl+Shift+B 显示书签栏。
  2. 把下面这个蓝色按钮拖到书签栏（不要点击它）：
    iBOM 取证
  3. 登录 https://ibom.sgmw.com.cn，停在任意页面，点书签栏里的「iBOM 取证」。
  4. 等约 1 分钟。浏览器会下载两个文件：ibom_phase0_<时间>.json 和 数模设计审核流程报表_<日期>.xlsx。
若浏览器提示「此网站尝试下载多个文件」，请点允许，否则只会下载到第一个文件。
想看进度可按 F12 打开 Console，日志前缀为 [ibom-probe]。

方式二：控制台粘贴（书签被拦截时用）

  1. 登录 iBOM 后按 F12 → Console。首次粘贴先输入 allow pasting 并回车。
  2. 点下面的「复制脚本」，粘贴到 Console，回车。

跑完之后

  1. 把下载的 JSON 和 xlsx 交回（直接上传，或放进 .runtime/ibom-impact/phase0/）。
  2. 请一位不同角色的同事也点一次书签，交回他的 JSON（对比可见范围）。
  3. 附一份最近的 TDC 数模 47 列导出 xlsx（求单号交集）。
