iBOM 取证工具

生产机无需安装 Python。三样工具都只读：只调用查询与导出接口，不发起审批、不改配置、不发送账号密码。

第一步：把两个按钮拖到书签栏（只需一次）

  1. 按 Ctrl+Shift+B 显示书签栏。
  2. 把下面两个按钮分别拖到书签栏（不要点击）：
    iBOM 取证 VSE 取证

第二步：在 VSE Toolbox 页面点「VSE 取证」

  1. 打开 VSE Toolbox 网页（地址以 http://127.0.0.1 开头），停在任意页面。
  2. 点书签栏里的「VSE 取证」，几秒后下载 vse_phase0b_<时间>.json。

读取数模归档任务与 D5 绑定实际填写的筛选条件，以及最新一份数模快照的流水单号，用来和 iBOM 单号求交集。

第三步：在 iBOM 页面点「iBOM 取证」（已经跑过可跳过）

  1. 登录 https://ibom.sgmw.com.cn，停在任意页面，点「iBOM 取证」。
  2. 约 1 分钟后下载 ibom_phase0_<时间>.json 与报表 xlsx。浏览器提示「下载多个文件」时点允许。

第四步：运行 PowerShell 脚本，记录 iBOM 登录跳转链

  1. 点「下载 PowerShell 脚本」，文件保存为 ibom_sso_chain.ps1（默认在下载目录）。
  2. 按 Win+R，输入 powershell 回车，在窗口里运行： 
    powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\ibom_sso_chain.ps1"
  3. 结束后下载目录里多出 ibom_sso_chain_<时间>.json。
如果公司策略不允许运行脚本文件：打开 PowerShell 窗口，点「复制脚本内容」，在窗口里右键粘贴并回车，效果相同。
脚本以未登录状态访问 iBOM，不使用 Windows 身份认证、不发送密码，只记录跳转经过的地址、参数名和 Cookie 名。
