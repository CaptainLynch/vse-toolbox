# WebUI 安全诊断录制

状态：Active。实现：`core/diagnostic_recording.py`、`web/diagnostics.py`、`web/static/diagnostics.js`。

## 现场操作

1. 在页面右下角展开「诊断录制」，点击「开始诊断」。也可用 `python webui.py --diagnostics` 或 `VSE-WebUI.exe --diagnostics` 启动。
2. 正常复现问题，点击「标记问题」保留时间点。
3. 点击「停止录制」，选择对应录制，下载诊断 ZIP；需要时可以下载录制中的快照。
4. 离开生产环境后，先阅读 `summary.md`，再用 `trace_id` 和 `span_id` 对照 `events.jsonl`。

默认录制30分钟、每次100 MiB。下次开始时清理7天以前或超过500 MiB逻辑保留额度的旧记录。SQLite存在页面、索引和WAL开销，磁盘占用不等于逻辑事件额度。原有诊断Markdown和旧交付物debug-bundle不自动加入新包。

程序异常退出后，已提交事件仍可在下次启动选择导出。没有结束事件不等于已经证明崩溃：可能仍在执行、达到时间/容量限制或写入失败。录制到期后不继续写入；无需保持页面在线。

## 覆盖范围

- 前端请求关联、按钮动作关联、JS异常位置及问题标记。
- Web API开始/结束、HTTP/业务结果；统一域认证和会话边界。
- Aras/TDC认证HTTP阶段、查询、分页、筛选解析、缓存、解析、下载和导出。
- 项目状态同步、连接器、更新策略、数据库事务/租约/快照写入。
- 定时归档任务、重试、归档写入和留存；租约心跳线程继承关联上下文。
- Office COM、Excel Worker、Excel API明确排除。XLSX文件的纯解析/预览属于Aras/TDC下载链路，仍记录阶段，完全不调用Office。

后台CLI运行器自动发现同一应用数据目录下的有效录制，建立独立任务trace。WebUI和计划任务必须使用包含此功能的同版源码/程序，并共享 `app_root()/data/diagnostics`。旧版CLI或位于另一应用目录的任务不会自动被覆盖；单独复制新版WebUI EXE不能升级另一份旧CLI。

## 数据与安全

诊断存储与业务SQLite分离，位置是 `data/diagnostics/recordings.sqlite3`。启停、状态、前端事件和下载接口全部校验回环地址、Host和Origin，拒绝跨站访问，不上传外部服务。

事件进入存储前使用结构投影：只保留固定阶段、计数、状态、已知路径、有限结构样本。字符串使用同次录制内稳定的带密钥指纹；未知字段名也可能变为指纹。这样可以比较选择与实际请求是否一致，但不能还原原值或自动重放。结构样本最多三项、字典最多32项、深度最多三层；不提供原始响应正文模式。

不保存密码/Cookie/Token/认证头、凭据引用、完整请求/响应正文、工作簿、完整数据库、环境变量内容、DOM文本、异常消息或局部变量。异常仅保留类型、代码文件名、函数名、行号及最多五层异常链的有限栈帧，并保留 errno/winerror/HRESULT 等数值错误码。已有独立日志文件不自动收集，因此不会把历史未审查日志带入ZIP。

## 包结构和证据边界

- `summary.md`：异常、失败响应、问题标记与未完成步骤数量。
- `manifest.json`：格式版本、录制边界、文件校验值、未完成步骤、已观察到的进程丢弃计数及限制。
- `environment.json`：运行平台、Python版本、构建指纹、冻结状态、是否设置代理。每条事件另带进程构建标识；EXE模式使用可执行文件SHA256，可识别录制期间进程重启或混用版本。
- `events.jsonl`：可关联的结构化时间线。
- `exceptions.json`：异常事件子集。

诊断事件采用短SQLite事务，进程内串行写入，跨进程写锁等待上限50ms。使用WAL并保持录制连接，避免每条事件反复触发关闭连接检查点。锁竞争/磁盘异常时丢弃诊断，不替换业务结果；成功事件携带本进程累计丢弃数。进程突然退出前最后的丢弃数可能没有落盘，清单不会将“零个已观察到的丢弃”当作绝对完整性证明。

## API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/diagnostics` | 状态及最近20次录制，直接返回状态对象 |
| POST | `/api/diagnostics/start` | 开始30分钟录制，返回状态对象 |
| POST | `/api/diagnostics/stop` | 停止并返回状态对象 |
| POST | `/api/diagnostics/mark` | 标记问题时间点 |
| POST | `/api/diagnostics/events` | 有限前端事件，每5秒最多100条 |
| GET | `/api/diagnostics/bundles/<id>` | 下载指定录制快照ZIP |

POST需提供JSON正文（控制操作用 `{}`），正文上限4096字节；下载仅接受系统生成的32位十六进制ID，不能指定路径。诊断接口不递归记录自身。Flask debugger和自动重载始终关闭。
