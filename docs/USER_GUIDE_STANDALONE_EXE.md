# VSE Toolbox 无依赖 EXE 使用说明

> 状态：Active
> 读者：Operator、User
> 权威来源：当前 WebUI/Worker EXE 构建和生产验收
> 默认读取：按独立 EXE 使用任务读取

> 适用对象：`VSE-WebUI.exe` + `VSE-ExcelWorker.exe`（零依赖独立可执行程序）。
> 无需安装 Python、pip 或任何第三方库，解压即用。本文全部截图取自实际运行的程序界面。

---

## 1. 这是什么

VSE Toolbox 是一套**汽车行业项目管理自动化工具箱**，覆盖项目状态总览、Aras（PLM）报表抓取、
TDC 报表导出、交付物目录、Excel 文件批处理与定时自动下载归档。

“无依赖 EXE”指使用 PyInstaller 打包的独立可执行文件：内部已内嵌 Python 3.12 运行时与全部
依赖库，目标电脑**不需要配置任何开发环境**，普通用户权限即可运行。

## 2. 运行架构

推荐以「Web 工作台」方式使用：双击 `VSE-WebUI.exe` 后，用浏览器操作全部功能；
涉及 Excel 真实读写时，主进程会自动调起同目录下的 `VSE-ExcelWorker.exe` 独立完成，
两者物理隔离，Excel 崩溃不影响 Web 服务。

## 3. 交付物清单

最新构建位于 `dist/VSE-WebUI-production-20260917/`（2026-09-17 生产测试包，配套 ZIP 传输包为 `dist/VSE-WebUI-production-20260917.zip`）：

| 文件 | 作用 | 是否必需 |
|---|---|---|
| `VSE-WebUI.exe` | Web 工作台主进程（仪表盘、Aras、TDC、定时任务、设置） | 必需 |
| `VSE-ExcelWorker.exe` | Excel 自动化工作进程（真实 Office COM / xlwings 执行） | 使用 Excel 功能时必需 |
| `SHA256SUMS.txt` | 文件校验值清单 | 建议保留 |

**部署要求**：两个 exe 必须放在**同一个目录**（例如 `D:\VSE-Toolbox\`），主进程按
“同目录查找”规则拉起 Worker。把文件复制到任意可写目录即可，不需要安装步骤。

**完整性校验**（可选，PowerShell）：

```powershell
cd D:\VSE-Toolbox
Get-FileHash -Algorithm SHA256 .\VSE-WebUI.exe, .\VSE-ExcelWorker.exe
# 结果与随包的 SHA256SUMS.txt 逐条比对
```

## 4. 运行环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 / Server 2016+（64 位） |
| 用户权限 | 普通用户即可；需对 exe 所在目录有**写入权限**（数据存放在此处） |
| Office | 仅 Excel 文件处理功能需要已激活的 Microsoft Excel（2016/2019/2021/365） |
| 网络 | 本机 `127.0.0.1` 回环必须可用；使用 Aras / TDC 抓取时需能连通对应企业内网 |

> **数据放在哪？** 程序以“exe 所在目录”为根目录：数据库为 `<exe目录>\data\vse_toolbox.db`，
> 日志与输出文件也在 `data\` 下。若该目录只读，程序会自动改用
> `%LOCALAPPDATA%\VSE-Toolbox\`，控制台日志会打印实际使用的数据目录。

## 5. 首次运行须知

1. **SmartScreen 提示**：exe 未做代码签名，首次双击可能出现“Windows 已保护你的电脑”。
   点击 **更多信息 → 仍要运行** 即可（建议先按第 3 节校验过哈希再放行）。
2. **杀毒软件误报**：PyInstaller 单文件程序偶有误报，校验哈希一致后将目录加入白名单。
3. **不要同时开两份**：默认端口 `5000` 与 SQLite 数据库都不支持多实例抢占。

## 6. Web 工作台模式（推荐用法）

### 6.1 启动与访问

1. 双击 `VSE-WebUI.exe`（会保留一个控制台黑窗口，用于显示运行日志，**关闭窗口 = 停止服务**）。
   服务就绪后会**自动打开默认浏览器**并进入工作台首页；
   如需以无头方式运行（后台计划任务、自动化测试），可在 CMD 中使用：
   ```cmd
   VSE-WebUI.exe --no-browser
   ```
2. 打开浏览器访问 <http://127.0.0.1:5000>。

如端口被占用，可换端口启动（CMD）：

```cmd
set VSE_TOOLBOX_PORT=8080
VSE-WebUI.exe
```

> **界面说明**：文档中部分历史运行截图取自构建基准版本。最新界面已优化全局顶栏指示、原位登录浮层及设置分层。具体功能与交互以当前实际运行界面为准。

首页顶栏包含以下关键控件：
- **版本标识（Version Chip）**：真实展示当前程序版本（如源码运行显示 `开发工作区`，冻结包显示 `独立运行包` 或发布版本号）；点击可展开维护与运行环境详情弹窗，方便技术支持排查。
- **工作区导航**：切换 **概览 / Aras / 交付物 / Excel / 自动下载与留存 / 设置** 六个工作区。
- **企业会话状态栏**：全局实时分别展示 **Aras** 与 **TDC** 的会话连接状态（绿色为有效，黄色为已过期，灰色为未认证），并提供 **登录 / 切换** 按钮，点击可在任意页面打开原位登录弹窗。
- **任务中心（📋 任务）**：右上角任务按钮打开统一任务抽屉，详见 6.10。
- **主题切换**：右上角按钮可在深色、浅色主题间切换。

### 6.10 统一任务中心与后台任务

- **统一任务抽屉**：点击顶栏「📋 任务」打开抽屉，聚合展示 **系统抓取任务、Excel 批处理任务、EWO 增强导表任务** 三类记录，支持「运行中 / 已结束 / 全部」筛选、取消、重试与工件下载。
- **后台任务化**：「全量抓取」与大导出（Aras EWO/PAA 导出、TDC 数模/SOR 导出）提交后立即返回，进度实时显示在任务中心；抓取完成后面板自动展示结果，导出文件请在任务中心下载。
- **工件保留期**：导出与结果文件统一落盘至 `data\downloads\`，系统自动清理 **7 天**前的过期文件，无需手工清理。
- **取消语义**：全量抓取支持在分页边界协作式取消（约 2 秒内响应）；任务失败会保留脱敏后的错误信息。
- **EWO 冻结重试红线**：EWO 增强导表任务出现「生成结果未知（generation_unknown）」时，任务中心**不提供自动重发**，仅允许在 EWO 增强导表面板人工核查状态后处理，避免向源系统重复发起生成请求。
- **凭据红线**：后台任务不支持账号密码或显式 Cookie 模式（凭据禁止入库持久化）；请先在「设置 → 统一域账号登录」完成登录，再提交后台抓取/导出任务。

### 6.11 数据表格交互增强

查询与抓取结果表格已升级为交互网格：

- **点击表头排序**：单击切换升序 → 降序 → 取消；按住 `Shift` 点击可叠加多列排序（表头显示 ▲/▼ 与次序标号）。
- **关键字快筛**：表格顶部输入框实时过滤并高亮命中关键字，无需点击查询按钮。
- **紧凑分页**：每页 50 / 100 条可切换，显示「共 N 条 · 第 x/y 页」。
- **列显隐偏好**：「列显隐」面板支持 **常用列 / 全量列** 一键切换与逐列多选，自定义结果保存在本机浏览器（localStorage），下次查询自动恢复；敏感列（Cookie、Token 等）始终被排除。
- **一键复制单号**：鼠标悬浮单号类单元格（EWO号、SOR号、编号等）时出现 📋 图标，点击即复制（不支持剪贴板 API 的环境自动降级为兼容复制方式）。

### 6.12 交付物明细页：数据同步摘要卡与自动同步向导

- **数据同步摘要卡**：交付物明细页顶部固定展示「数据同步」摘要卡，显示当前同步状态标签、
  最近尝试 / 最近成功时间与脱敏后的最近错误；未启用同步时提示当前为手工维护或待配置。
- **开启自动同步向导**（可同步交付物）：点「开启自动同步」展开轻量向导，只需两步输入——
  1. **同步凭据引用**：已在系统设置登录并勾选“保存至凭据保护库”时自动选中统一域账号
     （只保存凭据别名引用，不保存用户名或密码）；
  2. **外部编号**：按提示填写一个外部单号（如 EWO 号）。
  点「开始配置并启用」后系统自动完成：抓取映射证据（需连续两次一致的脱敏取证，2/2）→
  从最新脱敏字段报告推导字段映射 → 保存同步绑定 → 自动触发一次首同步并显示结果。
  候选记录不唯一时会让您选择一次目标记录；**推导不出字段映射时向导会明确提示原因并引导
  打开「高级设置」手工完成映射后保存**，系统绝不猜测映射。
- **立即同步**：已启用自动同步的交付物，摘要卡提供「立即同步」按钮，点击即从来源系统
  拉取一次最新数据，完成后显示成功 / 部分字段已应用 / 需要处理 / 失败及脱敏原因。
- **高级设置**：完整绑定表单（匹配规则、字段映射、更新方式切换等）整体收起在「高级设置」
  折叠区内，日常操作无需展开。

### 6.13 自动同步常驻调度

- **默认开启**：`VSE-WebUI.exe` 启动时自动拉起项目状态同步调度线程，按间隔为已启用的
  自动同步交付物做补偿性后台同步；距上次成功同步不足一个间隔的绑定直接跳过，
  不产生网络请求。
- **调整间隔**：设置环境变量 `VSE_PROJECT_STATUS_SYNC_INTERVAL`（单位：秒，正整数），
  默认 `900`（15 分钟）；非法值自动回落默认。CMD 示例：

  ```cmd
  set VSE_PROJECT_STATUS_SYNC_INTERVAL=1800
  VSE-WebUI.exe
  ```

- **关闭调度**：如需完全关闭常驻调度（例如只想手工点「立即同步」），CMD 中使用：

  ```cmd
  VSE-WebUI.exe --no-sync-scheduler
  ```

  关闭后不影响手工同步，也不影响“自动下载与留存”页的定时归档任务。

### 6.14 外部快照交付物（PAA 报告 / NCR 审批进度 / NCR 审批明细）

- **PAA 报告、NCR 审批进度、NCR 审批明细**三项交付物由定时归档写入的表单快照自动驱动：
  它们同样出现在概览「交付物明细」表格与状态环图中，带 **“外部快照·参考”** 徽标。
- 状态由最新有效表单快照自动映射（仅作展示参考），明细页中**只读**，不可手工编辑；
  尚无快照时显示“待同步”，不展示编造进度。
- 这三项为参考性外部快照，**不计入总体进度统计分母**；没有独立的“自动同步”连接器，
  数据随定时归档任务的表单快照自动更新。

### 6.15 表单快照统计分析（“统计分析”折叠区）

支持表单快照的交付物在明细页提供「统计分析」折叠区，展开时按需读取最新快照的
确定性统计结果（纯统计学计算，无 AI）：

- **停滞天数**：在途记录的停滞天数 = 当前日期 − 最后活动日期（优先当前节点到达日，
  回退提交 / 申请日期）；时间列缺失或非法的记录剔除出停滞统计并单独计数。
- **指标卡**：在途记录停滞天数的平均停滞、中位数、标准差与最长停滞；无在途停滞记录
  （或时间列不可用）时显示“-”，仅展示状态分布。
- **状态分布**：按状态统计记录数与占比。
- **停滞 Top5**：停滞最长的 5 条在途记录（单号、当前步骤、状态、停滞天数）。
- **离散度排名（跨快照方差）**：基于最近历史快照，对同一单号至少两次观测的记录按停滞
  天数方差降序排名；历史快照不足时提示暂无排名。
- 该交付物尚无快照时显示“暂无快照数据”。

### 6.2 概览：项目状态一屏掌握

![概览页面](images/exe-guide/01-overview.png)

- **主计划时间轴**：按当前阶段展示项目关键节点与完成状态（如“VPI-T2 主计划时间轴”），“今天”
  红线右侧即未来节点；点击 **编辑主计划** 可修改节点日期。
- **阶段概况**：当前阶段、总体进度、已完成 / 待同步 / 总计、风险/逾期数量一目了然。
- **交付物完成状态**：环形图逐项显示每条流程的完成度与状态。已接入来源同步的交付物显示
  快照进度；尚未配置同步、同步中、同步失败、无来源记录或已暂停的显示对应状态标签
  （不展示占位进度）。**点击环形图可直接进入该交付物的明细与分析页**。
- **交付物明细页**提供「更新方式」配置：可同步的交付物（SOR 定点流程 / EWO 流程 /
  数模设计审核流程报表）支持 **手工维护 / 自动同步 / 混合模式**——绑定统一域账号、
  填写匹配规则并连续两次抓取一致的映射证据后即可启用；启用后点 **立即同步** 即可从
  来源系统自动更新负责人、计划完成日期与风险备注，环形图与明细表随之显示快照结果。
  摘要卡、一键开启向导与常驻同步调度的日常用法见 6.12 / 6.13；外部快照交付物与
  “统计分析”折叠区见 6.14 / 6.15。
- 顶部子页签 **交付物明细**、**主计划维护** 可切换到交付物表格视图（可进入单条交付物的明细与
  编辑页）与计划编辑视图。

### 6.3 Aras：EWO / PAA / NCR 报表查询与导出

![Aras 页面](images/exe-guide/02-aras.png)

1. 右上角选择报表类型：**EWO / PAA / NCR 进度 / NCR 明细**。
2. 报表查询复用企业统一域账号认证（通过顶栏“登录 / 切换”或在“设置”中完成登录），系统使用内存安全会话向企业系统发起请求，不保存明文密码，不再需要手动配置浏览器 Cookie 或复杂的 HTTP 请求头。
3. 在 **查询字段** 中按编号、项目代码、关键词、日期范围等条件过滤。
4. 点击 **查询预览** 先看少量数据，确认无误后点 **全量导出 CSV**（Excel 可直接打开）。
5. 勾选 **保存 Aras XML** 可额外留存请求/返回报文，用于审计取证（下载请求 XML / 下载返回 XML）。

> **原位登录与操作恢复**：若查询时企业会话已过期，页面错误区将明确提示“企业域账号会话已过期”，并提供 **重新登录** 按钮；点击后将在当前页面弹出登录浮层。登录成功后，原页面填写的查询条件、表单草稿与已有结果**完整保留**，点击 **继续查询** 即可恢复获取数据，无需跳转或重新填写表单。

### 6.4 交付物：报表功能目录

![交付物页面](images/exe-guide/03-deliverables.png)

左侧是全部交付物/报表目录（含可用、仅占位、部分实现等状态标签），右侧显示所选条目的说明与
**“在 Aras 工作区打开”** 等入口按钮。顶部可按分类、状态筛选并刷新目录。
灰色的“仅占位/已禁用”条目属于规划中功能，暂不可用。

打开具体条目后可进入操作表单：直接使用统一企业会话与查询条件，
支持 **查询预览 / 全量抓取 / 导出下载**。TDC 数模设计审核与 SOR 报表额外提供两种查询模式：
**快速查询（list 接口）** 与 **官方 Excel 精确预览（较慢，与内网报表列完全一致）**，
查询后可直接 **下载 XLSX**。如遇到会话失效，同样可在原位直接完成登录并继续操作。

### 6.5 Excel：文件批处理（合并 / 叠加 / 比对）

![Excel 页面](images/exe-guide/04-excel-tasks.png)

1. 首次使用先完成 **Excel 文件处理服务配置**（未配置时页面顶部会提示，可在本页或“设置”页完成）。
2. **创建 Excel 处理任务**：选择处理方式（如追加合并）、文件所在位置（白名单目录下拉选择）、
   填写要处理的文件清单；比对类任务再指定对比基准。
3. 点击 **开始处理**，任务进入队列，由后台 Worker 进程逐个执行。
4. 下方 **处理记录 / 处理历史 / 输出文件** 可查看执行进度并下载生成的 `.xlsx`；
   **文件清理建议** 会按保留天数提示可清理的历史文件。

涉及真实 Excel 读写时需要启动 Worker，见 6.7。

### 6.6 自动下载与留存：定时任务

![定时任务页面](images/exe-guide/05-scheduled-archive.png)

- 左侧是自动下载任务列表（Aras EWO / PAA / NCR 进度 / NCR 明细、数模设计审核流程报表、TDC SOR 等），
  点 **新建任务** 可添加自定义任务；每个任务卡片与详情页均提供 **删除任务**（归档式移出列表，
  带并发保护，配置被他人改动时会提示刷新重试），也可用 **复制任务** 基于现有任务快速建新。
- 右侧配置单个任务：勾选 **启用自动下载**（内置任务可禁用）、设置 **自动执行频率（分钟）** 与
  **失败后最多尝试次数**；**定时登录信息** 引用“设置”页保存的域账号（存入 Windows 凭据保护库，
  不保存明文）；**归档目录** 支持三种方式：直接输入路径、点 **Windows 选择文件夹** 弹窗选择、
  或点 **使用系统默认**。
- **保存设置** 生效后可点 **立即下载一次** 做手工触发验证；**下载记录 / 设置变更记录** 页签保留完整
  历史供追溯。

> “Windows 选择文件夹”弹窗依赖桌面会话，请勿在服务/无人值守会话中使用该按钮，直接填路径即可。

### 6.7 设置：日常与高级维护分层

![设置页面](images/exe-guide/06-settings.png)

系统设置采用业务分层设计，日常高频配置一目了然，底层实现字段与低频参数安全折叠：

- **日常业务目录设置（默认展开）**：
  - **归档保存目录**：定时自动下载与历史归档数据的存放位置（留空使用默认 `data/archive`）。
  - **Excel 工作目录**：Excel 文件批处理任务的默认文件读写根目录（留空使用默认 `data/excel`）。
- **高级与维护设置（默认折叠）**：
  点击卡片标题展开后可配置系统运行参数（底层字段名已转为友好中文，折叠不影响配置的正常保存）：
  - **临时文件缓存目录**：数据处理中间文件的存放路径（留空使用系统临时目录）。
  - **系统诊断日志目录**：排查问题时的日志与诊断文件输出路径（留空使用默认 `logs`）。
  - **网络请求失败重试次数**：仅控制单次查询与在线抓取失败时的自动重试；定时下载任务的重试在对应任务卡中独立配置。
  - **默认定时下载周期**、**交付物临期预警阈值**、**历史快照保留数量**、**历史文件保留天数**。
- **企业认证会话与统一域登录**：
  - 分别查看 **Aras ECM** 与 **TDC 研发流程** 的认证状态与更新时间。
  - 通过统一域账号登录同时建立两端会话；密码仅在内存中用于校验，不落盘。
  - 勾选 **保存至凭据保护库** 时，凭据将写入本地 Windows 凭据管理器（DPAPI 加密保护），严格限定供后台定时自动下载使用；若未勾选，仅作为当前临时会话使用，权限不默认扩大。
- **Excel 文件处理服务**：显示服务配置与 Worker 进程状态；也可回到 Excel 页点 **启动 / 停止**
  控制 Worker（状态卡片在 `未运行` ↔ `运行中` 间切换）。

### 6.8 Worker 的启动与停止

- **界面方式（推荐）**：Excel 页点 **启动**，主进程自动调起同目录的 `VSE-ExcelWorker.exe`；
  点 **停止** 优雅停机（处理完当前文件后退出，不残留 `EXCEL.EXE` 进程）。
- **命令行方式**（适合批处理 / 计划任务）：

```cmd
:: 单次模式：处理完一个任务即退出
VSE-ExcelWorker.exe run-once --db data\vse_toolbox.db --root business=D:\ApprovedExcel

:: 常驻轮询模式：每 5 秒检查一次任务队列
VSE-ExcelWorker.exe run --db data\vse_toolbox.db --root business=D:\ApprovedExcel --poll-interval-seconds 5
```

- `--root 编号=目录` 定义**白名单根目录**，任务只允许读写白名单内的文件（防路径穿越）。
- `--no-json` 可切换为人类可读日志输出；常驻模式下按 `Ctrl+C` 优雅退出。
- 若 Worker 被强杀（如 `taskkill /F`），其持有的任务租约到期后会被标记为 `stale`，
  重新启动 Worker 后按重试策略自动恢复执行。

## 8. 停止与卸载

- **停止 Web 服务**：关闭 `VSE-WebUI.exe` 的控制台窗口，或在窗口内按 `Ctrl+C`。
- **停止 Worker**：Excel 页点 **停止**，或 `Ctrl+C` / 删除 stop 文件。
- **卸载**：直接删除部署目录即可；如需彻底清理本地数据，一并删除
  `%LOCALAPPDATA%\VSE-Toolbox\`（若存在）。

## 9. 常见问题（FAQ）

**Q1：双击后一闪而过 / 浏览器打不开 5000 端口？**
端口被占用或被安全软件拦截。用 `set VSE_TOOLBOX_PORT=8080` 换端口重启；确认控制台窗口未关闭。

**Q2：提示 “Approved root directory not found”？**
Excel 任务的文件必须在 `--root 编号=目录`（或界面中配置的工作目录）白名单内，且目录真实存在。

**Q3：Worker 执行任务时报 COM 错误 / 卡住？**
先手动打开一次 Excel，完成激活并关闭所有首次运行弹窗；再用任务管理器清理残留的
`EXCEL.EXE`（`taskkill /F /IM EXCEL.EXE`）后重试。

**Q4：Worker 被误杀后任务一直排队？**
任务租约超时后会自动标记 `stale` 并按重试策略恢复；重启 Worker 即可继续。

**Q5：密码会保存在哪里？**
查询类请求的密码仅当次使用、不落盘；定时任务的域账号凭据保存在 Windows DPAPI 凭据保护库，
只能由当前 Windows 用户解密。日志与接口返回中的敏感字段统一脱敏为 `[REDACTED]`。

**Q6：怎么确认下载的产物没损坏？**
任务审计记录中保存了产出文件的 SHA-256，可与本地文件 `Get-FileHash` 结果比对。

**Q7：想开机自启？**
创建 `VSE-WebUI.exe` 的快捷方式放入 `shell:startup`，或在任务计划程序中配置“登录时启动”。

### 查询状态与任务反馈指引（易用性第二阶段）

1. **查询结果状态与有效空结果**：
   - 当在 Aras 查询（EWO/PAA/NCR）或 TDC 交付物查询中检索到 0 条数据时，界面将显示明确的“未查询到符合条件的记录”卡片，并完好保留您的筛选草稿，方便随时微调条件重新查询；
   - 若某次查询之前已成功展示数据，但在后续重新查询时遇到网络抖动或异常，系统将保留原有的历史结果，并在结果区顶部标明“未能获取最新数据，已为您保留上次查询成功的历史结果”，避免页面数据骤然丢失。
2. **任务与归档操作反馈**：
   - Excel 任务面板在处理记录为空时，提供友好的操作引导说明；若列表网络拉取失败，可通过顶部【刷新】按钮重新读取；
   - 定时归档在网络读取下载记录失败时，会明确提示“后台已产生的归档文件不受影响”，区分界面展示失败与后台归档执行状态。
