## 1. 控制台脚本（A + B）

**操作（书签方式，推荐）**

1. 用浏览器打开 `tools/ibom_phase0_probe.html`，按页面提示把「iBOM 取证」按钮拖到书签栏（只需一次）。
2. 登录 `https://ibom.sgmw.com.cn`，停在任意页面，点书签栏里的「iBOM 取证」。
3. 等约 1 分钟。浏览器提示「此网站尝试下载多个文件」时点**允许**。
4. 下载目录里取两个文件：JSON 与报表 xlsx。

**备用（控制台方式）**：F12 → Console，首次粘贴先输入 `allow pasting` 回车，再粘贴 `tools/ibom_phase0_probe.js` 全文回车（安装页里有「复制脚本」按钮）。

**脚本自动导出的信息**

| 信息 | JSON 位置 | 回答的问题 |
|---|---|---|
| 账号角色、DMM 相关权限点 | `summary.roles`、`summary.dmmFunctions` | 正式接入账号的权限是否够用 |
| DMM 总数、状态分布、发布类型、项目名称、单号范围、全部单号 | `summary.dmm` | 可见范围；单号与 TDC 是否连续 |
| 造型 A 面总数 | `summary.asufTotal` | D4 是否开始有数据 |
| 能否按单号直接查询 | `summary.searchByCode_*` | 能否去掉「全量抓取 + 本地匹配」重路径（R10） |
| DMM 的 `recTypeId` | `summary.recTypes` | 工作流/附件/页签接口的前提 |
| 每种状态各 2 张样本的接口命中表 | `summary.samples[].hits` | **四个缺口各用哪个接口** |
| 明细（通用 `change/findById`） | `calls[]`（`step=sample:<单号>`） | 缺口①明细 |
| 零件数模列表（`loadEntity` × 8 种业务类型、猜测接口） | 同上 | 缺口②零件数模列表 |
| 签署栏（猜测接口） | 同上 | 缺口③内部签署栏 |
| 审批节点、流程实例、全部任务 | 同上（`approvalNodes`、`findProcesses`、`findAllTasks`） | 缺口④逐人签署状态 |
| 详情页页签清单 | `summary.contextMenus` | 详情页由哪些页签/接口组成 |
| 报表导出的状态、字节数、文件名 | `summary.export` | 报表能否作为数据源 |
| 页面可见的 Cookie 名（不含值） | `cookieNamesVisibleToJs` | 鉴权机制辅助判断 |

usertoken 已打码；结果里若检出 token，脚本会中止下载。

**样本覆盖要求**

脚本按状态自动取样（审批中、已发布、退回、草稿、取消各 2 张）。为了判断逐人签署状态，**审批中的样本里至少要有一张正处于「会签校对」节点、且已有人签、有人未签的单**。脚本跑完后看一下 `summary.samples`：

- 如果审批中的 2 张都不在会签节点，请在 iBOM 列表里找一张会签进行到一半的单，记下单号，一并告诉 Claude，可单独补测。
- 如果当时还没有「已发布」的单，照实说明即可。

## 3. TDC 数模导出（D）

交回任意一份**最近**的 TDC 数模 47 列 xlsx（含在途单）：本工具「系统查询 → TDC 数模 → 导出」的文件，或签署日报导入用的那份都可以。

用途：与 A 里的全部 iBOM 单号求交集，回答两个问题：

- 同一张 3D 单在两系统是否同号（决定关注清单、车型-架构单关联能否直接沿用）；
- TDC 是否仍在接收新单（决定阶段 2 能否做双源逐列比对、阶段 4 的回滚是不是「回到实时源」）。

## 4. 详情页抓包（E，视情况）

**仅当** A 的 `summary.samples[].hits` 里，签署栏或零件数模列表对应的候选接口全部是 `fail` 或 `empty` 时才需要。

1. 新开 InPrivate/无痕窗口，F12 → Network，勾选 **Preserve log**、**Disable cache**，类型选 **All**。
2. 登录 iBOM → 发布管理 → 数模设计审核流程。
3. 打开会签进行到一半的那张单，**依次点开所有页签**：基本信息、零件数模列表、内部签署栏、审批流程。
4. Network 面板右键 → Export HAR，交回。

报表 xlsx 已由脚本直接下载，这一步不用再导出报表。

## 5. SSO 跳转链（F，可选）

只在决定走「统一身份自动登录」路线时需要；若 IT 提供本地服务账号，可跳过。

1. DevTools 齿轮 → Preferences → Network，勾选 **Allow to generate HAR with sensitive data**（没有此项也可以继续）。
2. 新开 InPrivate/无痕窗口，先 F12 打开 Network，勾选 **Preserve log**，类型选 **All**。
3. 访问 `https://ibom.sgmw.com.cn` 并完成登录，直到首页加载完成。
4. 右键 → Export HAR（with sensitive data），交回。

需要的只是跳转经过的主机、路径和 Cookie 名，用于确认 `/fwPlatform/ssoAuth/login.api` 的落地方式。
