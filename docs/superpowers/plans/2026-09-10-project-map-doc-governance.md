**Goal:** Add a generated, allowlist-driven project map and classify the existing Markdown documentation so Agents can locate code without repository-wide scans.

**Architecture:** `PROJECT_MAP.md` is the compact Agent-facing view. `tools/generate_project_map.py` derives volatile file, symbol, route, build, and fingerprint data using standard-library AST without importing application modules. `AGENTS.md`, `memory/CONTEXT_MANIFEST.md`, and the map define the retrieval boundary; existing business code remains unchanged.

**Tech Stack:** Python 3.9+, `ast`, `pathlib`, `hashlib`, pytest, Markdown.

**Spec:** `docs/superpowers/specs/2026-09-10-project-map-doc-governance-design.md`
