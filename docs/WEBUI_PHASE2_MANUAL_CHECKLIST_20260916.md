## 一、验收用例清单

### 用例 1：Aras 查询有效空结果展示
- **入口**：顶栏导航 -> 点击【Aras】进入 Aras 查询工作台
- **合成/脱敏前置条件**：已连接或 Mock 会话就绪，输入一个不存在匹配数据的编号（例如 EWO 编号输入 `SYNTHETIC-NONEXISTENT-99999`）
- **操作步骤**：
  1. 在 EWO 表单中填写上述合成编号；
  2. 点击【查询预览】按钮。
- **预期结果**：
  1. 按钮显示“运行中”，请求完成后恢复；
  2. 结果区不再渲染带有“无结果”的空表格，而是展示带有搜索图标的空状态卡片：标题为“未查询到符合条件的记录”，正文明确提示“当前筛选条件下未返回任何数据记录。原表单查询条件已完好保留，您可以调整筛选条件后重新查询”；
  3. 表单中填写的输入内容完好保留，未被重置。
- **实际结果**：[待验]

### 用例 2：Aras 异常后历史结果保留与上下文提示
- **入口**：顶栏导航 -> 点击【Aras】
- **合成/脱敏前置条件**：此前已成功执行过一次有效查询并渲染了结果表格
- **操作步骤**：
  1. 断开模拟网络或输入触发后端的异常条件；
  2. 再次点击【查询预览】。
- **预期结果**：
  1. 请求失败后，顶部展示结构化错误卡片（包含影响、重新查询等操作）；
  2. 结果区上方的上下文提示条显示：“未能获取最新数据，已为您保留上次查询成功的历史结果（可检查上方错误提示后重试）”；
  3. 原表格中的历史数据完整保留，未被清空覆盖为全白或破坏布局。
- **实际结果**：[待验]

  2. 左侧目录选择与表单筛选草稿均未被重置。

### 用例 4：Excel 任务工作台列表引导与手动刷新
- **入口**：顶栏导航 -> 点击【Excel】
- **合成/脱敏前置条件**：本地 SQLite 数据库中尚无 Excel 任务，或筛选状态切换至无记录的状态（如 `已取消`）
- **操作步骤**：
  1. 查看左侧“处理记录”列表；
  2. 点击顶部工具栏的【刷新】按钮。
- **预期结果**：
  1. 列表区域展示友好的引导文本：“暂无处理记录。您可在上方选择操作类型并点击【开始处理】创建任务”；
  2. 点击【刷新】后触发重新拉取，界面保持平稳无报错；
  3. 若模拟网络错误（如关闭服务接口），列表显示明确的重试引导：“获取处理记录失败，请点击上方【刷新】重试”，并弹出错误说明卡片。
- **实际结果**：[待验]
- **验收人 / 日期**：[ ]

### 用例 5：定时归档记录读取失败与后台状态解耦
- **入口**：顶栏导航 -> 点击【定时归档】
- **合成/脱敏前置条件**：进入归档任务界面
- **操作步骤**：
  1. 查看右侧执行记录区域；
  2. 在网络断开或模拟后端返回异常的场景下点击【刷新】。
- **预期结果**：
  1. 执行记录区域明确提示：“获取下载记录失败（后台归档不受影响，可点击刷新重试）”；
  2. 清晰告知用户这只是前端网络读取记录失败，后台定时归档与已下载的文件完好无损，避免误导用户以为归档中断或执行失败。
