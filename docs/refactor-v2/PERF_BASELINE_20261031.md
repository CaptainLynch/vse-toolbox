# 性能基准测量报告（2026-10-31 基线）

## 1. 背景与目标

本报告建立 VSE-Toolbox 在 v2 架构重构前的系统性能基准线（Baseline）。
通过对应用冷加载、应用工厂构建、代表性只读 HTTP 接口以及 SQLite 大表分页性能的精确量化测量，为后续 W18-03 重构复测提供权威对比数据，严格把控架构演进中的性能质量。

---

## 2. 运行方法

基准测量脚本 `tools/perf_baseline.py` 严格遵循**零副作用**原则：
- 所有数据库及临时文件均在操作系统临时目录执行，退出时自动清理。
- 绝不改动生产代码，绝不向仓库内 `data/` 或任何源码目录写入数据。
- 失败时报清晰中文错误，退出码非零。

### 2.1 执行命令

- **全量基准测试（标准模式，每项 20 轮采样）：**
  ```bash
  python tools/perf_baseline.py --out .runtime/perf-baseline-20261031.json
  ```

- **快速基准测试（验证模式，每项 10 轮采样）：**
  ```bash
  python tools/perf_baseline.py --quick --out .runtime/perf-w18-01.json
  ```

- **自定义参数执行：**
  ```bash
  # 自定义 30 轮采样，大表扩充至 10000 行
  python tools/perf_baseline.py --rounds 30 --db-rows 10000 --out .runtime/perf-custom.json
  ```

### 2.2 参数说明

| 参数 | 类型 | 默认值 | 作用说明 |
| :--- | :--- | :--- | :--- |
| `--quick` | 标志 | 关 (False) | 快速模式：采样轮数从 20 减半至 10 轮 |
| `--rounds` | 整数 | None | 显式指定路由与分页测试的采样轮数 |
| `--db-rows`| 整数 | 5000 | 合成大表测试数据行数（不得低于 5000 行） |
| `--out` | 路径 | None | 将完整的结构化测试摘要输出至指定文件 |

### 5.1 劣化处置指引

若 W18-03 复测出现任何 **DEGRADED** 项：
1. **启动劣化**：核查重构后是否有新增重量级依赖被顶层无差别导入，推进惰性导入（lazy import）。
2. **路由响应劣化**：核查新增的中间件、拦截钩子或鉴权链路是否存在额外同步 I/O 或锁争用。
3. **数据库分页劣化**：核查重构后查询的 SQL 执行计划，确认关键排序列与过滤列的索引是否有效覆盖。
