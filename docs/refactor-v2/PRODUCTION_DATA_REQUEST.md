# v2 重构：需要从生产环境拿到的信息（从零操作指南）

> 配套：[架构方案](ARCHITECTURE.md) §8 M0、§9 · 采集工具：`tools/env-probe/`（probe 1.1）
> 一句话：**把一个约 15 KB 的压缩包发给 2–3 位同事，各自双击运行一次，填一张问卷，再把结果发回来。**

## 1. 为什么要这些信息

v2 方案中有 4 个前提只能在真实办公电脑上验证（架构 §8 M0）。另外，体验改造需要知道大家实际在用什么。

| 要回答的问题 | 影响的设计 | 信息来源 |
|---|---|---|
| S1：同事电脑的 Excel 是 32 位还是 64 位？用自带的 Python 能否通过 COM 驱动 Excel？ | 运行时的位数、Excel 处理方案 | 脚本 §7（会真的启动一次 Excel 做读写测试） |
| S2：用户目录里的程序能否运行？杀毒软件是哪家？有没有 AppLocker 等程序限制？ | 启动器形态、是否需要代码签名证书 | 脚本 §4、§5 |
| S3：有没有 WebView2 和 Edge？是什么版本？有没有被策略禁用？ | 桌面窗口能否用，还是退回 Edge `--app` | 脚本 §6 |
| S4：能否写 HKCU（文件关联、开机自启）？聊天软件收到的文件放在哪里？ | 双击安装更新包、自动发现更新包 | 脚本 §3、§4 + 问卷 B |
| 系统版本、内存、屏幕分辨率与缩放、区域与编码 | 窗口默认尺寸、中文路径和编码处理 | 脚本 §2、§8 |
| 能否连通 Aras / TDC / 帆软？是否走代理？ | 网络层与错误提示设计 | 脚本 §9（只做 HEAD 请求，不登录） |
| 现有版本、数据量、哪些功能真的在用、接口耗时、常见错误类型 | 迁移方案、功能优先级、性能基线 | 脚本 §10–§12（需要程序正在运行） |
| 有多少人用、最烦什么、车型和科室的取值、周报 PPT 与内网抓取是否保留 | 首页「今天」、筛选下拉框、K1 取舍 | 问卷 |

## 2. 隐私边界（发给同事前可以转述）

- **不采集**：密码、Cookie、登录令牌、Windows 凭据库、数据库文件、报表内容、日志正文、人名、单号。
- 使用统计只记录**结构、数量、状态值**（例如"任务 37 个，其中 failed 3 个"），不记录任何字段的文字内容；字段名里含 password/token/cookie/session 的一律标为 `<不采集>`。
- 日志只统计**级别、模块名、异常类型的出现次数**。
- 用户名、电脑名、域名在输出里统一替换为 `<user>` / `<pc>` / `<domain>`。
- 结果先落在同事自己的桌面上，同事看过 `summary.txt` 后自己决定是否发送。
- 三个写入测试都在测完后立即删除，加 `-NoWriteTest` 可以全部跳过。

## 3. 你要做的事（维护者侧）

### 第 1 步：拿到采集包
采集包已经打好：`.runtime\env-probe\vse-env-probe-1.1.zip`，里面有 4 个文件：`RUN-ME.cmd`、`vse_env_probe.ps1`、`README.txt`、`questionnaire.txt`。
如需重新打包，在仓库根目录运行：

```powershell
Compress-Archive -Path tools\env-probe\* -DestinationPath .runtime\env-probe\vse-env-probe-1.1.zip -Force
```

### 第 2 步：选 2–3 台电脑
尽量覆盖不同情况：**不同科室**、**新旧电脑各一台**，以及**至少一台正在用 VSE Toolbox 的**。你自己的办公电脑也算一台，建议先在自己的电脑上跑，熟悉流程。

### 第 3 步：发给同事
通过飞书或 QQ 发送 zip，同时附上这段话（可以直接复制）：

> 帮忙在你电脑上跑一个只读的检查脚本，大约 1 分钟，不需要管理员权限：解压到桌面 → 先打开 VSE Toolbox（没装就算了）→ 关掉 Excel → 双击 RUN-ME.cmd。跑完桌面上会多出一个 VSE-env-xxx.zip，你先打开里面的 summary.txt 看一眼，再把它和填好的 questionnaire.txt 一起发我。不会采集密码和业务数据。

### 第 4 步：处理常见问题

| 现象 | 处理 |
|---|---|
| 蓝色的"Windows 已保护你的电脑" | 点"更多信息 → 仍要运行"（这本身也是一条有用的结果，在问卷 E4 里记一下） |
| 黑色窗口一闪而过，或提示脚本被禁止运行 | 说明公司策略不允许运行 PowerShell 脚本，**这也是重要结论**。截图发回，只填问卷 E 部分。**不要**为了运行它去修改公司电脑的安全设置 |
| 摘要里写"Excel 正在运行，跳过" | 关掉所有 Excel 后重跑一次 |
| 摘要里写"使用统计：未读取" | 先打开 VSE Toolbox 再重跑；本来就没装的电脑可以忽略 |

### 第 5 步：把结果交给我
把收回来的文件放到仓库的 `.runtime\env-probe\results\` 下（这个目录**不进 git**），每台电脑一个子文件夹，例如：

```
.runtime\env-probe\results\
├─ 01-自己\VSE-env-20261029-0910.zip + questionnaire.txt
├─ 02-车身科\…
└─ 03-内饰科\…
```

然后告诉我"结果放好了"。我会读取 `report.json`，输出一份 M0 结论：哪些前提成立、哪些要改设计，并据此更新架构方案。

## 4. 我会怎么用这些数据

| 结论 | 决定什么 |
|---|---|
| Excel 位数分布、COM 测试是否通过 | 运行时打包 32 位还是 64 位 Python（Python 的位数必须和 Office 一致，否则 COM 调用会出问题） |
| `exeRunsFromLocalAppData` + 杀毒软件列表 | 启动器放在哪里、是否必须申请代码签名证书 |
| WebView2 覆盖率 | 默认使用桌面窗口，还是默认使用 Edge `--app` |
| HKCU 是否可写 + 聊天软件接收文件夹 | 双击安装、自动发现能否按设计实现 |
| 接口耗时与首页耗时 | 体验改造的性能目标（例如首页 < 1 秒） |
| 任务的类型和状态分布、错误类型排名 | 「今天」页先放哪些卡片，先修哪些错误 |
| 问卷 A6/A7 | 首次使用向导和错误卡片的具体文案 |
