## 八项问题的最终实现口径

| 问题 | 原因与实现 |
|---|---|
| 1 映射后仍能编辑 | 原 UI 无条件提供入口，PATCH 只加人工锁；现 API 输出共享编辑能力，DB 在事务内复核映射，已绑定或异常配置拒绝手工写入；模式和暂停状态不代替目标判断。 |
| 2 EWO 增强导表 | 基础列表缺待签人与要求完成时间，异步官方报表补充这些字段；结果仍只读、不回写主状态。主区突出业务结果，任务诊断折叠，未知生成结果不提供直接重发。 |
| 3 筛选跳动 | 原选项变化即请求并重建整个区域；现草稿等显式应用，同页签保留筛选节点，区分请求条件与成功结果条件，失败保留结果。 |
| 4 PAA/NCR 缺失 | 它们只有归档快照、没有正式阶段交付物身份；首期以两张外部业务快照参考卡展示完成数/总数，不改变交付物或节点分母，NCR 明细不重复计数。 |
| 5 全项目风险卡 | 移除模板独立卡和渲染调用。 |
| 6 外部同步概况卡 | 移除模板独立卡和渲染函数；业务快照卡明确来源范围与数据时间。 |
| 7 本节点交付物 | 节点规则未配置导致固定占位；无规则时隐藏该区域，保留节点标题、时间和主计划维护。 |
| 8 本节点风险与备注 | 同一节点规则缺失，首期隐藏占位；没有凭空增加节点隶属编辑或风险写入模型。 |
