# 交付物与控制台手工 UI 验证清单

本任务按用户要求不运行 UI 单元测试、前端源码断言或浏览器自动测试。以下项目由用户在内网手工验证；后端自动回归不能替代这些交互与视觉检查。

状态：实现、后端验证与代码审计已完成；以下复选框均留待用户手工验收，当前不代表任何 UI 项已通过。关联 [审计报告](DELIVERABLE_CONSOLE_AUDIT_20260916.md)。

## 受影响 UI

| 页面/区域 | 改动 |
|---|---|
| 状态总览 | 增加 PAA、NCR 快照进度卡；移除全项目风险及外部同步概况 |
| 当前节点 | 未配置范围时隐藏节点交付物/风险占位区域，保留时间及主计划入口 |
| 交付物明细列表、展开行、详情页 | 按后端权限控制编辑及行内备注 |
| EWO/SOR/数模/PAA/NCR 表单分析 | 筛选条件批量应用、加载期间保留交互区域 |
| EWO 补充报表 | 业务结果优先、任务详情折叠、按状态提供获取/恢复操作 |

## 1. 编辑权限

- [ ] 未配置映射的手工项可以编辑六个字段并保存，刷新后值一致。
- [ ] 默认 automatic 但尚无绑定目标的项不会仅因模式被锁定。
- [ ] 已配置单条/集合映射的项编辑入口禁用，显示只读原因；列表、展开行、详情、行内备注一致。
- [ ] 暂停同步、同步失败、暂无快照时，已配置映射项仍不能编辑。
- [ ] 两个窗口中，一处打开未关联项编辑，另一处配置关联，再从旧表单保存：出现只读提示，没有覆盖数据。
- [ ] 未关联项两个窗口修改同一记录，旧版本保存仍提示冲突。

## 2. 筛选与滚动

- [ ] 在靠下位置连续选择/取消多项，页面不跳动、焦点与下拉状态合理、没有立即加载。
- [ ] 关键词、日期和多选共同点击“应用筛选”后生效，分页回到第一页。
- [ ] “清除筛选”重置并刷新一次，草稿提示和已应用标签一致。
- [ ] 切换表单页签后条件按页签隔离；返回时草稿和已应用状态符合提示。
- [ ] 慢网络下切换页签并模拟请求失败，旧结果的筛选/图表/分页被锁定，不能串写新页签；重试、返回旧页签及快速连续切换均正确，成功加载后恢复交互。
- [ ] 慢网络下连续应用两组条件，最终结果属于最后一次请求。
- [ ] 加载过程中继续编辑条件，不丢新草稿；失败后条件和旧结果保留，并可重试。
- [ ] 请求未完成时离开详情再返回，不出现旧页面结果覆盖新页面。
- [ ] 图表点击筛选、标签删除、分页、刷新表单数据仍能工作。

## 3. PAA/NCR 进度

- [ ] 总览出现 PAA 与 NCR 两张卡，NCR 明细没有重复计入。
- [ ] 卡片完成数、总数、比例与同范围快照摘要一致，NCR 按业务记录去重。
- [ ] 无快照显示待同步/不可用；有效空快照显示暂无数据，均不显示 100%。
- [ ] 上次快照有效但最新同步失败时保留快照并提示异常/时间。
- [ ] 显示来源范围说明及快照时间；不冒充当前项目范围、不进入节点完成率。
- [ ] 点击卡片可进入对应外部详情，NCR 明细入口仍可用。
- [ ] 修改详情临时筛选不会改变总览固定快照范围。

## 4. EWO 补充信息

- [ ] 标题、待签人/要求完成时间、获取时间可理解；技术任务详情默认折叠。
- [ ] 打开详情或普通刷新不会自动生成官方报表。
- [ ] 显式准备、生成、读取能完成，主操作按钮随状态变化，没有重复提交。
- [ ] 有文件引用的下载失败只继续读取原报表；生成结果未知提示始终可见，不能直接重发同一任务。
- [ ] 范围改变/登录身份改变后旧结果不误用；返回页面可恢复符合当前范围的任务。
- [ ] 下载/解析失败时主结果区显示错误；继续读取沿用已生成文件，不再次生成。
- [ ] “关联状态”与“EWO状态”分列，待签人来自“当前阶段未签署的角色&人员”，责任工程师单独展示。
- [ ] 基础记录 ID、计数和诊断仍可在“获取详情”找到。
- [ ] 增强结果不改变项目负责人、计划日期或备注。

## 5. 页面清理与回归

- [ ] 全项目风险与备注、外部同步 PAA/NCR 概况不再显示，也没有留下空卡片。
- [ ] 未配置节点范围时仅保留节点标题、时间与主计划入口，无交付物/风险占位文案。
- [ ] 编辑主计划、交付物明细、归档任务配置/重试仍可使用。
- [ ] 常用窗口宽度及窄窗口布局无溢出，键盘可访问操作入口，浏览器控制台无新错误。
